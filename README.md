# IPO Web Application

This is the frontend of a stock exchange-based IPO (Initial Public Offering) web application, developed as part of a 2-month internship project. The application allows users to browse upcoming IPOs, register/login, and view key financial and company details.

> This is the implementation — It is completed using **HTML, CSS, and JavaScript**.

---

##  Features Implemented

- Home Page
- Analytics page
- mutual funds page
- Technical Analysis page
- Products page
- Contact us page
